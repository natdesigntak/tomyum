# Shopee Auto Video Review Assistant (Prototype)

> ภาษาไทย: โครงสร้างต้นแบบสำหรับสร้างวิดีโอรีวิวสินค้า + ช่วยเตรียมข้อมูลสำหรับอัปโหลดบน Shopee แบบกึ่งอัตโนมัติ

## สิ่งที่โปรเจกต์นี้ทำได้

1. ดึงข้อมูลสินค้า (ผ่านไฟล์อินพุต JSON/CSV ที่คุณเตรียมเอง)
2. สร้างสคริปต์รีวิวอัตโนมัติ
3. สร้างเสียงพากย์ (TTS)
4. รวมภาพ/คลิปสินค้า + เสียงพากย์เป็นวิดีโอ
5. สร้างไฟล์ metadata สำหรับการอัปโหลด
6. มี Chrome Extension โหมดช่วยกรอกฟอร์มในหน้าเว็บ Shopee

## ข้อจำกัดสำคัญ

- การ **อัปโหลดและปักตะกร้าแบบอัตโนมัติ 100%** อาจขัดกับข้อกำหนดแพลตฟอร์ม Shopee หากจำลองการกด/บอท
- แนะนำให้ใช้แบบ **human-in-the-loop**: ระบบเตรียมทุกอย่าง แล้วให้คนกดยืนยันขั้นสุดท้าย
- ถ้าต้องการอัตโนมัติเต็มรูปแบบ ควรใช้ API ทางการ (หาก Shopee เปิดให้)

## โครงสร้าง

- `pipeline.py` — ตัว orchestrator หลัก
- `sample_products.json` — ตัวอย่างข้อมูลสินค้า
- `templates/review_prompt.txt` — เทมเพลตสคริปต์รีวิว
- `chrome-extension/` — ส่วนช่วยกรอกข้อมูลหน้าอัปโหลด

## วิธีใช้งานอย่างเร็ว

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python pipeline.py --input sample_products.json --output out/
```

ผลลัพธ์จะได้:

- `out/videos/*.mp4`
- `out/metadata/*.json`
